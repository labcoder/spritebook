# Using SpriteBook

Start with the bundled offline example if you want to try the editor before downloading models. Use
an image when you want SpriteBook to generate a new character, or import an existing mesh and keep
its authored rig.

| Task                                       | Guide                                                                                                                            |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |

| Tune cameras, output sizes and exports     | [Capture and export](capture.md)                                                                                                 |
| Work through the editor's six stages       | [Studio guide](guide.md)                                                                                                         |
| Open, back up, close or delete a character | [Projects and files](projects.md)                                                                                                |
| Install, verify or repair models           | [Models and runtimes](models.md)                                                                                                 |
| Use optional Blender or bundled content    | [Extensions](extensions.md)                                                                                                      |

| Diagnose a failed job or unexpected output | [Troubleshooting](troubleshooting.md)                                                                                            |
| Bring sprites into an engine               | [Godot](engines/godot.md), [Unity](engines/unity-texturepacker.md), [Phaser](engines/phaser.md), [Aseprite](engines/aseprite.md) |

SpriteBook currently qualifies its desktop workflow on Windows x64. Check
[platform support](../platform-support.md) and [model requirements](models.md) before installing AI
backends. Exporting an existing authored character needs no model download; rendering still needs a
working GPU adapter.

Your character data stays on your machine. Initial model and runtime setup downloads third-party
files after the required consent. [Licensing](../licensing.md) explains the separate terms for the
application, model components and input assets.
