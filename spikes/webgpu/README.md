# P0-T2 — headless WebGPU spike

**Throwaway by contract** (see `docs/internal/roadmap/p0.md`). Nothing here is production code; the
measurements in [REPORT.md](./REPORT.md) are the deliverable. This spike exists to make D-004 (TS
core on Deno + WebGPU) true or false.

## Run

```sh
deno task spike:webgpu:gen                  # regenerate assets/skinned-column.glb (hermetic, procedural)
deno task spike:webgpu                      # full suite: bar batch, determinism, shear, soak, 512px
deno task spike:webgpu                      # run twice: second run adds the cross-process determinism check
deno task spike:webgpu -- --mode=fault      # panic probe — run LAST, in its own invocation (may abort by design)
```

Backend pinning: `DENO_WEBGPU_BACKEND=dx12|vulkan deno task spike:webgpu`.

## What it does

- Loads a small skinned glTF (4-joint chain, generated by `gen-asset.ts` via glTF-Transform —
  procedural so the spike is hermetic and license-free).
- Skins in WGSL with joint matrices in a storage buffer; renders MRT (lit rgba8unorm + linearized
  view-depth to r32float) offscreen; depth24plus is used for z-test only, never read.
- Reads back with 256-byte `bytesPerRow` padding, strips padding, encodes PNGs with fast-png.
- Double-buffered readback (pool of 3 slots), no per-frame `mapAsync` await.
- Pass bar (roadmap): ≥5 f/s aggregate, 100 frames, 2 attachments @128 px; width-100 shear test;
  same-process double render → identical bytes.
- Supplementary evidence (kept cheap): 1000-frame sustained soak with RSS sampling, 512 px batch,
  cross-process determinism, PRD workload projections, fault-injection postscript.
