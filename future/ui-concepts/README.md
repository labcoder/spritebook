# Historical design studies

These HTML studies record earlier visual directions. They are not the shipping app or executable
product tests. The current interface lives in `apps/studio/src`; its identity is documented in
`apps/studio/DESIGN.md`.

Production lint excludes this archive, as it excludes spikes and qualification fixtures. Shipping
components, assets and tests retain their checks. Keep the studies as references rather than copying
their static markup into the application.
