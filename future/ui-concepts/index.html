This is a design study

These controls explore SpriteBook’s visual identity. Recording a look is disabled here; no manifest, model, or application setting is changed.

The CLI twin in the application remains part of the proposed design. This sample command describes the saved camera and style:

Desktop composition scaled to fit. “Inspect at 100%” keeps the sprite at integer zoom; scroll to inspect the full window. Menu, stage, and tab labels are illustrative.

Identity

A warm charcoal shell, apricot actions, generous grouping, and soft rectangular controls. IBM Plex Sans carries the interface; mono is reserved for measurements and CLI.

Why it fits

Feels like a creative desktop tool and lets varied character artwork lead. The same system can cover the gallery, model manager, and six stages.

Tradeoff

The quieter identity is less distinctive from other creative apps. Its warmth, wordmark, and spacing would need consistent execution.

What is real in this study?

The eight walk strips are unmodified output from the completed Windows Pixal3D qualification, bake acc25412, recorded on 20 October 2026. The character is named Juniper for this study; the real character ID is pixal. Camera and style controls are illustrative. The existing OFL fonts are reused. This study does not establish new model runs, platform support, export parity, or native accessibility.
